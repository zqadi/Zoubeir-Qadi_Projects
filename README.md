# Python for Data Science, AI & Development

## Overview

This repository contains Python exercises, Jupyter notebooks, and practice projects completed while learning Python for Data Science, AI & Development through Coursera.

## Topics Covered

- Python fundamentals: variables, expressions, strings, and data types
- Data structures: lists, tuples, sets, and dictionaries
- Control flow: conditions and loops
- Functions and object-oriented programming
- File handling and data loading
- NumPy and pandas fundamentals
- HTTP requests and API fundamentals
- Web scraping exercises
- Text analysis

## Tools & Technologies

- Python
- Jupyter Notebook
- NumPy
- pandas
- HTTP requests and APIs

## Repository Structure

The notebooks are organized by course lesson and topic. Each notebook contains practice exercises or course-related work.

## Learning Objectives

- Build a foundation in Python programming.
- Practice working with data structures and files.
- Develop familiarity with data analysis libraries.
- Understand basic API requests and web scraping concepts.

## Next Steps

Apply these foundational skills to independent projects involving data analysis, operational reporting, and business process automation.
